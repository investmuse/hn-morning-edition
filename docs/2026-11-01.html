It's the memory latency, stupid

Lüks tüketici psikolojisi ile veri biliminin kesişimidir.

According to Richard Sites, memory latency is much slower (between 250x and 1000x) than processors, while memory bandwidth is improving at a better rate but is still slower than processors (between 30x and 100x). Stuart Cheshire notes that latency is usually about 100ms, about 300 times worse than Ethernet, and suggests a sensible latency target for modems with a transmission rate of 28.8kb/s is about 5ms. CPU cache latency and throughput are much better than memory.
